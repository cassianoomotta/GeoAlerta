# Ticket 19 — Comprovar restauração em alvo descartável

## Implementação local

O comando `npm run test:restore` agora faz dump do schema `public` com `pg_dump` e restaura em um destino vazio com `pg_restore`, sem limpar o destino. A guarda exige origem e destino distintos na `TEST_DATABASE_ALLOWLIST`, impede colisão com o banco operacional e exige `RESTORE_SOURCE_IS_SYNTHETIC=true` antes de qualquer conexão. O snapshot compara hashes e contagens por tabela, sequências, extensões, constraints não validadas, políticas e objetos de esquema. O relatório não expõe credenciais nem valores das linhas; Auth e bytes de Storage são declarados como limites separados.

- `npx tsc --noEmit` — aprovado.
- `npm run test:unit` — aprovado: 108 testes.

- `npm run test:restore` com origem sintética deliberadamente não confirmada — recusado antes de conectar a bancos, com relatório sanitizado.
